# Replaceable input components

Set `TextaloniaEditor.KeyboardComponent`, `PointerComponent`, `CaretComponent`, or `CompositionComponent` to replace that responsibility. Null restores the corresponding default. The demo installs a keyboard component that selects the next word on F6 and a blue caret; its remaining shortcuts, clipboard, selection and native IME use the defaults.

A component receives a `DocumentInputContext` on the UI thread only while its surface has an editor and is attached to a visual tree. Its `Editor`, `Session`, caret rectangle, hit testing, line boundaries and viewport height use the shared document layout. Components do not own committed document snapshots. `ICompositionComponent.PreviewDocument` is transient and disappears on cancellation, replacement, read-only changes, focus loss, or visual detachment. Text input is dispatched to composition independently of keyboard bindings, so a custom keymap does not need to implement IME commits.

Avalonia tunnel/handled input takes precedence. The surface forwards only unhandled key, text and pointer events whose original source is the surface; focused inline controls retain their own input and shortcuts. The selected component is the only component called for its responsibility. It must set `Handled` when consuming an event. Derive from `DefaultKeyboardComponent` and call `base.KeyDown(e)` for fall-through to standard shortcuts; an unhandled event is otherwise left to Avalonia's remaining route. Composition client requests are serviced independently. Pointer capture-lost notifications always reach the attached pointer component so it can clear drag state.

An instance belongs to one attached surface at a time. `DocumentInputComponent` enforces that rule and offers `OnAttached`/`OnDetached` overrides. Do not retain the context after detachment. Release external subscriptions, timers and pointer capture in `OnDetached`; the defaults do this. Replacing a component detaches the old one before attaching its replacement. Replacing the template or removing the editor from the visual tree detaches every component; reattachment creates a fresh context. The native composition component also invalidates previous IME clients, preventing late platform callbacks from updating a new surface. The surface does not dispose host component instances, which can be reused after detachment.

Default keyboard commands retain session read-only checks, undo grouping, platform primary modifiers, word movement, table navigation and selection behavior. Cancel composition before a custom command changes selection or document content. Session changes also invalidate a composition preview when its base document or selection changes.
